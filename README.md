# Renegade X Chinese Localization

A work-in-progress Simplified Chinese translation of Renegade X, using HarmonyOS Sans.

持续完善中的 Renegade X 简体中文汉化，使用 HarmonyOS Sans 字体。

## Version branches / 版本分支

Translation packages are maintained in branches named after the compatible Renegade X game version. Select the branch that matches your game before downloading or installing.

汉化文件按所适配的 Renegade X 游戏版本分别维护。下载或安装前，请切换到与你的游戏版本一致的分支。

| Game version / 游戏版本 | Branch / 分支 | Status / 状态 |
| --- | --- | --- |
| Release 1.1.1094 | [`1.1.1094`](../../tree/1.1.1094) | Work in progress / 持续完善中 |
| Release 1.0.1022 | [`1.0.1022`](../../tree/1.0.1022) | Work in progress / 持续完善中 |

The `main` branch only contains project information and licensing. Installable files are kept in the version branches.

`main` 分支只保存项目说明和许可证；可安装文件位于对应的版本分支。
